# Macro du Split Push

> Gagner sans fight. Forcer l'adversaire à choisir entre perdre des structures ou perdre un fight.

---

## Le principe

Le splitpush crée un **dilemme** pour l'adversaire :
- Envoyer 1 pour stopper le splitpusher → le splitpusher doit gagner le duel
- Envoyer 2+ → notre équipe a un avantage numérique sur le reste de la map
- Ignorer → on prend les structures

**Pour que ce soit efficace : le splitpusher doit être une vraie menace 1v1.**

---

## Les 4 phases du splitpush

**Phase 1 — Établir la pression**
- Arriver sur la side avec une grosse vague (slow push préparé)
- Montrer ta présence pour forcer le response adverse

**Phase 2 — Lire le response**
- Combien viennent ? Ont-ils le TP ?
- Si 1 vient : peut-on le kill ou faut-il push vite et se barrer ?
- Si 2+ viennent : signal pour l'équipe de prendre un objectif

**Phase 3 — Communicate avec l'équipe**
- Ping dès que tu vois le response adverse se déplacer
- L'équipe a ~15-20s pour réagir avant que le response arrive sur toi

**Phase 4 — Reset ou continue**
- Si objectif pris → reset, rejoindre l'équipe ou reprendre la side
- Si objectif raté → recalibrer, ne pas mourir pour rien

---

## Conditions pour splitpusher

- Champion avec un **win condition 1v1** claire
- Items de splitpush (Guinsoo, Trinity, Iceborn, etc. selon champ)
- Ward coverage sur les chemins d'accès (sweeper + wards)
- TP ou mobilité pour rejoindre l'équipe si nécessaire

---

## La règle du TP

Si le splitpusher a TP → il peut participer aux fights à travers la map. C'est un atout énorme.
Sans TP → il est locké sur sa side. L'équipe doit jouer sans lui dans les fights.

**Règle** : avant d'utiliser TP pour rejoindre un fight, s'assurer que c'est le bon moment (objectif à prendre, fight gagnable). Un TP raté = perte du splitpush ET du fight.

---

## Erreurs classiques

- Continuer à push après que l'adversaire ait 4 personnes qui arrivent
- Mourir bêtement → réinitialiser toute la pression de la game
- Ignorer les pings d'objectifs de l'équipe pendant le split
- Ne pas avoir de ward coverage → se faire prendre de dos
