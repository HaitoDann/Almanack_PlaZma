# Wave Management Fundamentals

> La vague est une ressource. La gérer, c'est contrôler le tempo de la game.

---

## Les 3 états d'une vague

Une vague est toujours dans un des trois états. Voir [[Slow_Push_vs_Hard_Push_vs_Freeze]] pour le détail.

| État | Description | Quand l'utiliser |
|------|-------------|-----------------|
| **Freeze** | Garder la vague à portée de ta tour | Se défendre, denyer le farm adverse |
| **Slow Push** | Accumuler une grosse vague sans hâte | Setup un back ou un objectif |
| **Hard Push** | Vider la vague le plus vite possible | Roam, back, objectif immédiat |

---

## La règle du recall

**Avant chaque recall** : la vague doit être dans un état contrôlé.

- Recall avec une vague en freeze → elle devient freeze pour l'adversaire. ❌
- Recall avec une grosse vague slow push qui arrive sur la tour → elle gère la tour pendant ton absence. ✅
- Recall avec une vague neutre → l'adversaire la freeze facilement. ⚠️

---

## Numéros de vague critiques

Les vagues ne sont pas toutes égales. Les vagues à connaître :
- **Vague 3-4** : premier back possible si first blood pris
- **Vague 6-7** : spike de niveau 6, première fight window
- **Vague 9-11** : premier item spike (Lv1 + base de 2nd), macro decison critique

---

## La valeur d'une vague

Une vague complète = environ 14 CS = environ **294g** (vague standard 7 melee + 3 casters).
Une vague canon = bonus +46g.

Ne jamais "laisser passer" une vague inconsciemment. Chaque vague manquée = or perdu.

---

## Asymétrie de vague

Si tu arrives sur ta lane avec 40 minions adverses sous ta tour :
- Ne pas les push vite → c'est un lure. L'adversaire te setup un gank.
- Option A : freeze sous ta tour et garder l'échange équitable
- Option B : push si tu as la vision et la priorité de jungle
