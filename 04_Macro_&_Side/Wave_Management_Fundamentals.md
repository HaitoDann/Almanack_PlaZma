# Wave Management Fundamentals

> L'art de manipuler les sbires pour que ça tourne à notre avantage.

---

## Composition d'une vague

| Timing | Composition |
|--------|-------------|
| 0 à 15 min | 3 mêlés + 3 mages + 1 canon sur 1 vague sur 3 |
| 15 à 25 min | 1 vague sur 2 contient un sbire canon |
| Après 25 min | Toutes les vagues contiennent un sbire canon |
| Après inhibiteur tombé | 3 mêlés + 3 mages + 1 super sbire (2 super si 3 inhibiteurs tombent) |

L'intervalle entre deux vagues est de **30 secondes**.

---

## Dégâts des tourelles sur les sbires

| Type de sbire | % de PV perdus par tir de tourelle |
|---------------|-----------------------------------|
| Mêlé | 45% |
| Mage | 70% |
| Canon | 14% |
| Super sbire | 10% |

→ Priorité de push : les sbires mages meurent en 2 tirs de tour, les canons résistent.

---

## Comportement des sbires

- Les tourelles attaquent les sbires du plus proche au moins proche
- Les sbires prennent l'aggro de **la première entité qu'ils voient** (champion ou sbire)
- Si tu lances une auto sur un champion adverse alors qu'un sbire est à côté → le sbire t'attaque

**La règle d'aggro est centrale dans le freeze et le trade sous tour.**

---

## Les 3 états d'une vague

Voir [[Slow_Push_vs_Hard_Push_vs_Freeze]] pour le détail complet.

| État | Objectif |
|------|----------|
| **Freeze** | Garder la vague proche de ta tour, denyer l'adversaire |
| **Slow Push** | Construire une grosse vague progressivement |
| **Hard Push** | Vider la vague le plus vite possible |

---

## La règle du recall

Avant chaque recall → la vague doit être dans un état contrôlé.

- Recall avec une vague en freeze → elle devient freeze pour l'adversaire ❌
- Recall avec un slow push qui arrive sur la tour adverse → elle gère la tour seule ✅
- Recall avec une vague neutre → l'adversaire la freeze facilement ⚠️

---

## La valeur d'une vague

Une vague standard (7 mêlés + 3 mages) ≈ **14 CS ≈ 294g**.
Une vague avec sbire canon = bonus supplémentaire.

Ne jamais laisser passer une vague inconsciemment. Chaque vague manquée = or perdu.
