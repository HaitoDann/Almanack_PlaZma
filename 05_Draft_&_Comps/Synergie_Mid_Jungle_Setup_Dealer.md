# Synergie Mid Jungle — Setup & Dealer

> Le duo qui décide du tempo de la game. L'un setup, l'autre exécute.

---

## Le principe

Le mid et le jungle partagent le centre de la map. Leur synergie est la plus impactante sur le tempo early/mid game.

Deux rôles à clarifier dans le duo :
- **Le Setup** : crée les conditions du kill (CC, engage, slow)
- **Le Dealer** : deal le kill quand la fenêtre s'ouvre

**Le setup sans dealer → pas de kill. Le dealer sans setup → pas de fenêtre.**

---

## Les 4 archétypes de synergie Mid/Jungle

**Engage + Assassin**
Setup engage en jungle/mid → assassin jump sur la cible immobilisée.
→ Exemple : Sejuani + Zed / Diana + Katarina
→ Extrêmement forte sur les picks isolés, moins sur les 5v5

**Poke + Diver**
Mid poke en continu → jungle dive quand la cible est basse.
→ Exemple : Jayce + Jarvan / Zoe + Vi
→ Demande coordination : le dive doit partir quand le poke a suffisamment usé

**CC chain + Burst**
CC long du jungle → CC supplémentaire du mid → burst → zero réaction possible.
→ Exemple : Malphite + Orianna / Amumu + Annie
→ La combo teamfight la plus dévastatrice, mais prévisible

**Farm + Carry** *(moins de synergie active)*
Les deux farm et ne se soutiennent pas en early → plus solitaires.
→ Danger : peut perdre le mid game si l'adversaire a une synergie active

---

## Communication duo Mid/Jungle

**Obligatoire** :
- Le jungle annonce ses camps et ses timings de gank
- Le mid annonce la priorité de sa lane (peut-il aider ? a-t-il besoin d'aide ?)
- Accord sur qui engage et qui exécute **avant** le gank

**Erreur fréquente** : le jungle arrive en gank, le mid n'est pas prêt → kill manqué → flash perdu.

---

## Position du mid en relation au jungle

Si le jungle est côté top → le mid doit avoir une priorité de lane pour pouvoir rotate top rapidement.
Si le jungle clear bot → le mid couvre le milieu et empêche le counter-gank.

**Règle** : le mid et le jungle ne doivent jamais être "perdus" l'un par rapport à l'autre.

---

## Draft : identifier le duo

En phase de draft, identifier dès les premiers picks :
1. Est-ce qu'on a un setup ? → Sinon le draft le cherche
2. Est-ce qu'on a un dealer qui profite de ce setup ? → Idem

**Un duo déséquilibré (deux setups, zéro dealer) → les kills ne viennent jamais.**
