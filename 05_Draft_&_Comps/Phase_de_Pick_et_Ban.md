# Phase de Pick et Ban

> Comment lire et jouer le pick/ban. Chaque action est une information ou une prise de position.

---

## Structure du pick/ban (Best of 1)

```
BAN Phase 1 : Bleu ban 3 · Rouge ban 3
PICK Phase 1 : Bleu 1 · Rouge 2 · Bleu 2
BAN Phase 2 : Rouge ban 2 · Bleu ban 2
PICK Phase 2 : Rouge 1 · Bleu 2 · Rouge 2
```

---

## Les bans : stratégies

**Bans de confort adverse** : cibler le champion que le joueur adverse joue le mieux.
→ Demande du scouting. La question est : "Quel champion fait peur si l'adversaire le pick ?"

**Bans de compo** : retirer les champions clés d'un archétype pour neutraliser leur win condition.
→ Exemple : bannir Amumu + Orianna si l'adversaire joue systématiquement teamfight engage.

**Bans de pool** : retirer toutes les options sur un rôle pour forcer un pick non-optimal.
→ Risqué — l'adversaire peut avoir plus de profondeur de pool qu'on croit.

---

## Les picks : lecture des priorités

**Priorities** : des champions si forts sur le patch que ne pas les pick = les laisser à l'adversaire.

**Signal pick** : un pick qui révèle ton archétype de compo. Éviter de signaler trop tôt si on veut une compo surprise.

**Flex pick** : un champion qui peut jouer plusieurs rôles. Valeur maximale : l'adversaire ne sait pas où il va → force un ban ou un mispick.

---

## La règle du last pick

Le last pick est le plus puissant : il a toute l'information adverse.
Utiliser le last pick pour :
- Placer un counter de lane direct
- Compléter la win condition de la compo
- Fermer un trou dans les 5 piliers

---

## Les erreurs classiques

- **Reveal trop tôt** : montrer son archétype de compo en phase 1 → l'adversaire s'adapte
- **Ban sans cible** : bannir par peur d'un champion qu'on ne connaît pas → gaspillage
- **Ignorer le matchup** : pick ce qu'on veut jouer sans regarder ce que l'adversaire a
- **Pas de communication** : le pick/ban doit se faire avec un capitaine de draft + input des joueurs sur leurs matchups

---

## Protocole de draft

1. Avant le pick/ban : chaque joueur annonce ses 3 champions de pool disponibles
2. Le capitaine annonce la win condition visée
3. Phase de ban collective → le capitaine tranche
4. Phase de pick → chaque joueur valide son matchup sur ce qui a été draft
